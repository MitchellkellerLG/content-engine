# Skills

Plain-markdown instructions any AI coding assistant can follow (Claude Code, Codex, Cursor, and others that read `SKILL.md` files). Copy or symlink the folders into your assistant's skills directory, or just point the assistant at the file.

| Skill | Use it when |
|---|---|
| `content-orchestrator` | You want one place that walks a piece from idea to scheduled post, one step at a time |
| `daily-brief` | Morning: gather material, write the brief, score it |
| `voice-builder` | First run, and every month or two: build or refresh your voice files |
| `repurpose` | Turning a proven X post into LinkedIn + graphic + quote post |
| `no-ai-slop` | Editing any draft so it sounds like a person wrote it |
